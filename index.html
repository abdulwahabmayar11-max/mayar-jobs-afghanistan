مدیریت اعلان‌ها

این نسخه سایت ایستا است. اعلان‌ها در فایل jobs.json نگهداری می‌شوند؛ تغییرات این صفحه تا وقتی فایل را در GitHub به‌روز نکنید، برای دیگران منتشر نمی‌شود.

هشدار: این رمز داخل کد عمومی است و امنیت واقعی ایجاد نمی‌کند. برای سایت عمومی، آن را به‌عنوان قفل امن استفاده نکنید.

پس از صادرکردن JSON، محتوای فایل را در jobs.json مخزن GitHub جایگزین و Commit changes کنید تا اعلان‌ها برای همه منتشر شوند.
